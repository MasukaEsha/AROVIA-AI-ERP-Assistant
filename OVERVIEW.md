# AI ERP Assistant

A beginner-friendly AI-powered ERP Assistant that lets users ask business questions in plain English and get answers from a real database.

**Who it's for:** Anyone who wants to query ERP data (sales, inventory, employees, customers, suppliers) without knowing SQL.

**How it works:**

1. User asks a question in natural language (e.g. "Which product sold the most?")
2. AI (Google Gemini) converts the question into a SQL query
3. The query runs against the database
4. AI formats the result into a human-readable answer

**Key features:**

- Dashboard with sales stats, charts, and low-stock alerts
- Chat interface for natural language ERP queries
- SQL safety validation (read-only queries only)
- 60 days of realistic sales data across 5 tables
